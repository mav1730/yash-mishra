# Yash Mishra — Applied AI Engineer

Personal site. Cream/ink/red. Vite + React.

## Pages

- `/` — home, work, license
- `/work` — case studies
- `/playground` — sketches + BeaconOps
- `/manifesto` — stuff list
- `/pinart` — mouse image trail

## Local

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

Deploy the `dist` folder on **Vercel** or **Netlify** (SPA rewrites are included). Connect this repo and the default Vite preset is enough.

Contact lives on the site under **Talk**.
